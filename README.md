# Live Futár

Magyar élő foci eredménykövető app (Jetpack Compose + Highlightly API).

## Változások (UI/UX + új funkciók)

- **Skeleton loading** – shimmer meccskártyák a betöltés alatt
- **Frissítés jelző** – felső progress sáv minden képernyőn (Élő is)
- **Élő kereső** – csapat / bajnokság szűrés az Élő képernyőn
- **Kedvenceim élőben** – kedvenc csapatok élő meccsei a lista tetején
- **Animációk** – kereső fade/expand, élő pont pulse komponens
- **Üres állapotok** – jobb szöveg keresésnél és üres élő listánál

## Fő funkciók

- Napi meccslista (lapozás), dátumváltás, 3h/6h/9h szűrő
- Élő meccsek auto-refresh (60s)
- Meccs részletek: events, odds, lineups, stats, momentum, H2H
- Highlight videók, fogadószelvény, kedvencek, tabella
- Widget + gól értesítések, téma / accent beállítások
